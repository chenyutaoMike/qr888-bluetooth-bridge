# 打印路径

```text
提交任务的 App
  → macOS CUPS 系统队列
  → 用户已安装的启锐 QR-888XPro PPD 与栅格过滤器
  → 本机 LPD 127.0.0.1:19150/qr888
  → 私有待预览目录与标签预览窗口
  → 用户确认
  → CoreBluetooth → 已选择的 QR-888XPro
```

打印桥先确认收到完整的 LPD 作业，再将它写入当前用户的待预览目录，并向 CUPS 确认接收。预览从原厂驱动的逐页 TSPL 压缩位图解码，显示印刷点阵、纸张尺寸和张数。无法完整解码的任务会禁用确认。

打印机列表按 QR-888XPro 广播名筛选，设备选择保存在当前 Mac 的 App 偏好设置中。确认打印时仅向已选择的设备连接，并验证其 `18F0` 服务与 `2AF1` 可写特征。蓝牙检查只验证连接和特征。

取消会移除本机待预览任务。确认会先将待预览任务标记为发送中，再发送原始驱动输出。重开 App 会恢复待预览作业。若上次退出时任务正处于发送中，App 会提示检查实际出纸。

CUPS 负责排版，桥接负责确认和传输。纸张、分辨率、浓度、走纸和标签感应仍与驱动及硬件有关。Apple 系统保留对 PPD 队列的支持时，现有集成才能工作。 [OpenPrinting CUPS 文档](https://openprinting.github.io/cups/doc/man-lpadmin.html)
